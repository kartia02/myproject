# 개인 기록 체험 구현 결정

## 목표

공개 포트폴리오에서 방문자가 반려동물 이름을 등록하고 실제 서비스처럼 체험할 수 있게 한다. 상업용 회원 서비스가 아니라 분석 구조와 개인정보 경계를 보여주는 범위로 구현한다.

## 구현 순서와 완료 상태

1. 이름 필수, 나이·견종 선택 프로필 등록
2. 합성 예시 즉시 체험과 직접 기록 시작 모드 분리
3. 개인 기록의 브라우저 저장·수정·삭제·JSON 내보내기
4. 30일 Baseline과 최근 7일 비교를 위한 37일 진행률 표시
5. 개인 기록 요청 API와 입력값 검증
6. 기존 Python 분석 및 Luna Agent 조사 흐름 연결
7. 이름·원본 기록·질문을 Neon에 남기지 않는 익명 실행 메타데이터 저장
8. Backend 자동 테스트, Frontend 빌드, 브라우저 저장 지속성 확인

위 항목은 모두 구현했다. 배포 환경은 기존 Vercel Frontend, Render Backend, Neon PostgreSQL 구성을 유지한다.

## 데이터 흐름

```text
브라우저에 저장된 프로필·일일 기록
        ↓ 분석 실행 시에만 전송
FastAPI 입력 검증
        ↓
Python Personal Baseline·변화 탐지
        ↓ 구조화된 Tool 결과
GPT-5.6 Luna Evidence 기반 설명
        ↓ 서버의 근거·표현 검증
사용자 결과 화면

Neon에는 익명 실행 상태·모드·Agent 사용량만 저장
```

## 의도적으로 제외한 범위

- 회원가입과 로그인
- 서버의 개인 프로필·원본 기록 보관
- 여러 기기 사이의 기록 동기화
- CSV 등 파일 업로드
- 수의학적 진단과 원인 단정

이 경계 덕분에 기존 무료 배포 구성을 유지하면서 방문자가 등록과 기록 흐름을 직접 확인할 수 있다. 실제 다중 사용자 서비스로 확장할 때는 인증, 사용자별 데이터 소유권, 동의·삭제 정책, 서버 저장 암호화와 마이그레이션을 별도 설계해야 한다.
